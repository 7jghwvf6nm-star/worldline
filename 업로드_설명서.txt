WORLDLINE GitHub Pages 업로드용

1. 이 ZIP을 iPad 파일 앱에서 압축 해제하세요.
2. GitHub > worldline 저장소 > Code > Add file(+) > Upload files.
3. ZIP 파일 자체를 올리지 말고, 압축 해제한 폴더 안의 아래 5개 파일을 선택하여 올리세요:
   index.html
   manifest.webmanifest
   sw.js
   icon-192.png
   icon-512.png
4. GitHub 저장소의 최상위에서 README.md 옆에 index.html이 보이는지 확인하세요.
5. Settings > Pages > Deploy from a branch > main > /(root) > Save.
6. Actions 탭에서 Pages build and deployment가 성공(녹색)인지 확인하세요.
7. 주소: https://7jghwvf6nm-star.github.io/worldline/

업로드용 ZIP 내부 최상위는 Worldline_App/ 폴더 없이 앱 파일들로만 구성되어 있습니다.
